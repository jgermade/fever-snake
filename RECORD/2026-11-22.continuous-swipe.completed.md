# Continuous swipe steering

## 2026-11-22

- Request: change direction without lifting the finger.
- Before: a swipe was read only on `pointerup`, one action per touch.
- Now `SwipeTracker` (`src/input.js`) follows the pointer while it is down.
  Every `step` px travelled from the anchor emits the dominant-axis action and
  moves the anchor, so an "L" stroke emits two turns. Step scales with the
  screen (14-26 px). The same action repeats only after `repeatSteps` x `step`
  (useful for relative controls in the Labyrinth). Coalesced pointer events
  are used and the pointer is captured. A touch that never travels `step` px
  is a tap.
- Verified: 6 new unit tests (L, zig-zag, no spam, repeat, tap, wobble);
  Chromium with emulated touch (Pixel 7, CDP touch events): one stroke
  down→left→up produced dirs right→down→left→up with the snake alive.
